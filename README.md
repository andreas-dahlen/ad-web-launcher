# ADWebLauncher

A WebView-based app launcher for Android 15.  
Includes HTML/CSS/JS assets, Kotlin code for WebView launcher service.

## Features
- Live WebView launcher
- Interactive buttons to launch apps via JS
- Full-screen HTML layout
- Placeholder clock/animations

## Structure
- `app/src/main/assets/` → HTML/CSS/JS
- `app/src/main/java/com/ad/weblauncher/` → Kotlin files
- `res/xml/launcher.xml` → launcher declaration

🟦 TS → logic
🟪 TSX → UI
🩷 CSS → styling (light pink, your idea is good)
🟠 types → structure
🟧 config → environment
🩵 hooks → reactive flow
🩶 utils → background helpers
🟡 tests → validation
